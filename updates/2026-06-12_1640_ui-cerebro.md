# UI do cérebro: dashboard web local em lab/ui/

**Sessão:** autoresearch (Mac mini), 2026-06-12 ~16h40.

## O que foi pedido

Pedro: "eu quero que isso [o cérebro] tenha uma ui pra que eu acesse,
entenda melhor, veja resultados."

## O que foi decidido

- UI **local, zero custo, zero dependências** (decisão de custos nº 2:
  assinatura Max, nada de infra paga). Python stdlib puro + um HTML único
  (markdown renderizado via marked.js de CDN, com fallback offline).
- Lê `lab/` e `updates/` **ao vivo a cada request** — sem build, sem cache,
  sem banco. Recarregar a página = estado atual dos arquivos.
- **Única escrita permitida**: marcar/desmarcar checkbox em
  `wiki/pendencias-globais.md` (grava `*(feito YYYY-MM-DD via UI)*`,
  seguindo a convenção da própria página). Resto é leitura.
- Servidor escuta em todas as interfaces → acessível via tailnet de
  outras máquinas também.

## O que foi construído

- `lab/ui/server.py` — servidor http stdlib, porta 8765. API JSON
  (`/api/overview|updates|wiki|agents|skills|scoreboard|changelog|file|toggle`)
  com guard de path (só lab/ e updates/; testado contra traversal).
  Toggle valida o conteúdo da linha antes de gravar (409 se o arquivo
  mudou desde o carregamento).
- `lab/ui/index.html` — SPA com sidebar: **Visão geral** (cards: pendências
  abertas, 114 agentes por status/domínio, updates, scoreboard, skills,
  inbox), **Pendências** (checkboxes interativos), **Decisões ativas**,
  **Updates** (timeline colapsável, mais recente aberto), **Wiki**,
  **Agentes** (tabela filtrável por nome/domínio/status, clique abre a
  definição num drawer), **Skills**, **Scoreboard** (com empty-state que
  explica o elo fraco da medição), **Changelog**.

## Como usar

```
python3 ~/Dev/autoresearch/lab/ui/server.py   # → http://localhost:8765
```

Servidor deixado RODANDO nesta máquina (porta 8765) ao fim da sessão.
Não sobrevive a reboot — relançar com o comando acima se cair.
